# MedReasoner — Research Prototype

Knowledge Graph-Augmented Clinical Decision Support System.

This repository contains the downloadable starter project archive: `MedReasoner_GitHub_Starter.zip`.

## Quick start
1. Download the ZIP from the repository (open the file and choose **Download raw file**).
2. Extract it on your computer.
3. Open a terminal in the extracted project folder.
4. Install dependencies with `pip install -r requirements.txt`.
5. Launch with `streamlit run app.py`.

## Important research and safety note
This is an educational software prototype, not a medical device or diagnostic tool. It uses synthetic demonstration inputs and a lightweight illustrative baseline. It does not reproduce the paper's full clinical Transformer, UMLS knowledge graph, MIMIC-III/IV experiments, or reported performance metrics. Do not use it for real patient-care decisions.
